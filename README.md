
# DatachainGUI - 无人机交通目标检测系统前端

## 📋 项目简介

DatachainGUI 是一个基于 **Streamlit** 开发的交通视频/图像目标检测可视化系统。该项目提供了一个用户友好的图形界面，集成了多个预训练的目标检测模型，支持图像和视频的实时推理与检测，适用于无人机航拍数据的智能分析。

## 🎯 核心功能

- **多模型支持**
  - Datachain 交通目标识别模型（Light / Base / Large）
  - COCO 通用识别模型（Light）
  - 灵活的模型切换机制

- **图像检测**
  - 支持 JPG、JPEG、PNG 等图像格式
  - 实时目标检测与标注
  - 一键下载结果图像

- **视频检测**
  - 支持 MP4、AVI、MOV 等视频格式
  - 逐帧实时推理处理
  - 进度条可视化
  - 输出结果视频文件

- **智能标注**
  - 检测框自动标注
  - 置信度显示
  - 类别识别标签

## 🛠️ 技术栈

| 框架/库 | 用途 |
|--------|------|
| **Streamlit** | Web 应用框架 |
| **YOLOv11** | 目标检测推理引擎 |
| **OpenCV** | 图像/视频处理 |
| **NumPy** | 数据处理 |
| **Pillow** | 图像操作 |

## 🚀 快速开始

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行应用
```bash
streamlit run infer_GUI.py
```

### 使用方式
1. 在侧边栏选择检测模型
2. 选择输入类型（图像或视频）
3. 上传待检测文件
4. 等待推理完成
5. 下载或查看检测结果
